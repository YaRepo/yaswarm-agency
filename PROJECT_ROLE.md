# Project Role

This repository is the **public YaSwarm product monorepo source**.

## Local Checkout Identity

- Local folder: `yaswarm-public-monorepo`
- GitHub repo: `YaRepo/yaswarm-agency`

## What It Is

This is the clean, public, production-oriented monorepo intended for external users to install, configure, and run with **their own data**.

## What It Is Not

This is **not** the active/private operator runtime system used internally to build or operate YaSwarm.

Do not confuse it with:
- `yaswarm-agency-ui`
- `yaswarm-desk-workspace`
- private/internal repos, sessions, logs, tokens, or founder-specific memory

## Working Rule

Any feature copied or ported here must be adapted for:
- public users,
- safe defaults,
- reproducible setup,
- production readiness,
- and zero personal/private data leakage.
