# Portfolio Pitch Builder

## Overview
Use this skill to transform raw project notes into polished portfolio and pitch assets.

## Workflow
1. Extract project facts from notes.
2. Build case structure: challenge, approach, execution, result.
3. Generate short and long variants for social, email, and deck.
4. Flag missing proof points and media assets.

## Safety Rules
- Mark unknown outcomes as "not provided".
- Avoid inflated claims without supporting data.

## Resources
- Case template: `references/case-template.md`
- Draft script: `scripts/build_case_study.py`

## Output Contract
1. Portfolio summary
2. Pitch paragraph
3. Proof gaps
4. Next assets to collect
