# Dialect Notes

## Arabic Variants
- `msa`: formal/standard Arabic used in writing and formal speech.
- `egy`: Egyptian colloquial Arabic used in daily spoken contexts.

## Guidance
- Prefer natural target-language phrasing over rigid literal conversion.
- Keep dialect-specific flavor when user asks for colloquial output.
- If source is mixed MSA + colloquial, choose dominant style and note this.
