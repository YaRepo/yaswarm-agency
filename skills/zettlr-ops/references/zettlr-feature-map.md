# Zettlr Feature Map (from local tutorial)

Key capabilities:
- Workspace-centric file management
- Markdown editor with interactive elements (checkboxes/tables)
- Internal links (`[[note]]`) and tag-driven relations
- Zettelkasten workflow with optional note IDs
- Citation system via references database (CSL JSON/Bib)
- Sidebar tabs for TOC, references, related files, attachments
- Split view and multi-window support
- LaTeX-backed export compatibility

Operational implication:
- Best automation surface is file-level markdown + references management.
