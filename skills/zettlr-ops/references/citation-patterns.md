# Citation Patterns

Common patterns:
- `@CiteKey` -> Author (Year)
- `@CiteKey [p. 12]` -> Author (Year, p. 12)
- `[@CiteKey, p. 12]` -> (Author Year, p. 12)

Checklist:
- Ensure `references.json` (or configured bibliography) exists.
- Ensure citekeys in text exist in reference database.
- Keep locator syntax consistent (`p.`/`pp.`/`chapter`).
