# Timeline Builder

Create and manage story timelines in Writing Desk.

## Instructions

When the user wants to build a timeline:

1. **Determine Scope**:
 - Universe history (centuries/millennia)
 - Story timeline (days/weeks/months)
 - Character backstory (years)
 - Work's plot events (scene by scene)

2. **Gather Events**:
 - Key historical events
 - Character births/deaths/major moments
 - Plot points and story beats
 - Concurrent events (parallel storylines)

3. **Create Timeline Document**

---

## Timeline Types

### Universe History
- Spans centuries or millennia
- Focuses on world-shaping events
- Establishes context for stories

### Story Timeline
- Spans the duration of one work
- Day-by-day or scene-by-scene
- Tracks parallel plotlines

### Character Backstory
- Birth to story start
- Key formative moments
- Explains current motivations

---

## Consistency Checks

When building timelines, verify:

- [ ] Character ages match events
- [ ] Travel times are realistic
- [ ] Seasons/weather align with dates
- [ ] No impossible simultaneity
- [ ] Referenced historical events are consistent
