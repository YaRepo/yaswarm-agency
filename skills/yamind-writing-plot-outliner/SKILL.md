# Plot Outliner

## Purpose
Turn a raw premise into an executable story blueprint with clear beats, stakes escalation, and chapter progression.

## Progressive Loading
- Fast path: `references/quickstart-runtime.md`
- Full framework templates: `references/full-playbook.md`

## Use This Skill When
- Use when the user needs a full outline before drafting.
- Use when an existing plot feels flat, confusing, or slow.
- Use when chapter-by-chapter beat alignment is required.
- Use when comparing plot frameworks for the same concept.

## Inputs
- Genre and target audience
- Story premise
- Protagonist goal
- Core conflict/antagonist
- Stakes and theme
- Target length (novella/novel/series)

## Workflow
1. Diagnose story type and select framework.
- Default picks:
  - Commercial fiction: Save the Cat
  - General fiction: Three-Act
  - Mythic fantasy/adventure: Hero's Journey
  - Episodic character arc: Story Circle
2. Define non-negotiables.
- Inciting event
- Midpoint shift
- All-is-lost collapse
- Irreversible climax decision
3. Build beat ladder.
- Map beats in order with one sentence each.
- Ensure every beat changes risk or information state.
4. Convert beats to chapter map.
- Assign chapter purpose and chapter-end hook.
- Add dependency notes for foreshadowing/payoff.
5. Stress-test the outline.
- Remove convenience beats.
- Verify protagonist agency at major turns.

## Framework Menu
- Three-Act Structure
- Save the Cat (15 beats)
- Hero's Journey (12 stages)
- Story Circle (8 steps)
- Seven-Point Structure
- Fichtean Curve
- Freytag's Pyramid
- 27-Chapter method

## Quality Rules
- Every act break must be irreversible.
- Every midpoint must reframe the mission.
- Every chapter must advance plot or character cost.
- No chapter closes on pure recap.

## Safety Rules
- Do not force framework dogma over story logic.
- Flag missing inputs instead of inventing canon facts.
- Keep project-specific canon constraints explicit.
- Separate draft options from final recommendations.

## Output Contract
1. Selected framework with brief rationale.
2. Ordered beat sheet with stakes progression.
3. Chapter map with purpose + end-hook per chapter.
4. Top revision risks and next outlining actions.
