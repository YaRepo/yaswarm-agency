# Plot Outliner Quickstart

Use this file when speed matters and only load the full framework templates if needed.

## Fast Workflow
1. Confirm story type and target length.
2. Choose one framework (default: Three-Act or Save the Cat).
3. Capture four anchors:
- Protagonist goal
- Core conflict
- Stakes
- Theme
4. Produce beat list and chapter mapping.
5. End with unresolved risk to validate before drafting.

## Framework Defaults
- Commercial thriller/romance: Save the Cat (15 beats)
- Literary/dramatic: Three-Act + Freytag blend
- Mythic/fantasy: Hero's Journey
- Episodic/character-driven: Story Circle

## Escalate to Full Templates When
- User asks for full beat-sheet scaffolds.
- Word-count-based chapter targets are required.
- Multi-framework comparison is requested.
