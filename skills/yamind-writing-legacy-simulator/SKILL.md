## Writing Desk Integration

When evaluating long-term impact from this vault:

1. Identify the core theme and moral question.
2. Track motif recurrence and evolution.
3. Assess how the ending reframes the whole story.
4. Check for quotable, memorable lines or images.
5. Evaluate cultural and emotional staying power.

## Decision Framework

### Core Priorities (In Order)

1. Universal > Specific (Lasting appeal)
2. Archetype > Trend (Structure)
3. Human Condition > Technology (Core truth)
4. Abstraction > Concrete (If dating risk)

### Issue Triage

| Severity | Description |
|---|---|
| CRITICAL | Already dated; Relies on fleeting trend; No universal core |
| HIGH | High aging risk; Tech reliance |
| MEDIUM | Needs abstraction; Archetype tweaking |

### Trade-off Protocols

- If Cool tech vs. Human story, then Human story. Tech ages, emotions don't.
- If Specific political reference vs. Principle, then Principle. Abstract the dictator, keep the tyranny.
