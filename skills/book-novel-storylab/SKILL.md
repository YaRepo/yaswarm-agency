# Book Novel Storylab

## Overview
Use this skill to plan, draft, and revise long-form fiction with clear structure and continuity.

## Workflow
1. Story foundation.
- Define premise, genre, tone, POV, themes.
- Set story promise and reader experience target.

2. Architecture.
- Build high-level outline (acts/parts/chapters).
- Map major beats, turning points, and stakes progression.

3. Character system.
- Build character sheets, motivations, wounds, and arc shifts.
- Track relationships and conflicts over time.

4. Scene drafting.
- Generate scene goals, conflict, and outcome per chapter.
- Draft in passes: rough -> clarity -> voice -> polish.

5. Revision and continuity.
- Run consistency checks for timeline, names, POV, and world rules.
- Flag pacing dips and unresolved setups.

## Safety Rules
- Preserve author voice preferences when provided.
- Mark co-created text as draft material.
- Avoid copying protected source text; write original prose.
