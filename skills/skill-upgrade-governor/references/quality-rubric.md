# Quality Rubric

Critical:
- Missing `SKILL.md`
- Invalid or missing frontmatter fields (`name`, `description`)
- Skill name mismatch vs folder intent

High:
- Missing `agents/openai.yaml`
- Description not actionable (does not state when to use)
- Missing safety rules or output contract

Medium:
- TODO/placeholders left in production skills
- Scripts present but not executable
- No references for complex workflows

Low:
- Excessive verbosity or repetition
- Inconsistent naming and style
