# Y.K.Y. Sadek Pen Style

Use this skill as a reference for the Y.K.Y. Sadek writing voice dynamic acoureding to the book/story/novel/novella/series/script/narrtive at hand. Load the style guide before drafting or rewriting.

## How to Use

1. Read the full style guide in `references/y-k-y-sadek-style.md`.
2. If needed, run the validator in `scripts/validate_yky_style.py` on a draft.
3. Identify the scene's emotional spine and surveillance pressure.
4. Apply the Cyber-Duat blend with restraint and dry British wit.

## Writing Desk Integration

When applying this style to vault content:

1. Identify the core fear and the surveillance pressure.
2. Fuse one mythic motif with one tech system.
3. Keep viewpoint tight and claustrophobic.
4. Add one dry-wit line that undercuts the horror.
5. Verify the mythic element feels ritualistic and costly.

## Quick Self-Check

- Tech feels invasive and alive.
- Myth feels ancient, heavy, and costly.
- Tone is cynical, claustrophobic, and controlled.
- Satire is dry and politically pointed.
- No high-fantasy gloss.
- Show don't tell rules applied.
