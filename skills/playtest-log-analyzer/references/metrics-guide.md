# Metrics Guide

Core metrics:
- Per-card appearance count
- Per-card win rate when present
- Overperformers: win rate >= 65% with sample >= 8
- Underperformers: win rate <= 35% with sample >= 8

Patch strategy:
- Overperformer: +1 cost or -1 stat / tighter timing window
- Underperformer: -1 cost or +1 stat / broaden trigger
