# Notes Style Guide

## Structure

- First line: title (`# Title`)
- Optional metadata block:
  - `Created:` ISO date
  - `Updated:` ISO date
  - `Category:` one taxonomy value
  - `Tags:` comma-separated
- `## Summary` short 1-3 sentence overview
- `## Notes` main content
- `## Action Items` checkbox list when relevant

## Rewrite Rules

- Preserve original meaning; improve clarity only.
- Convert vague bullets into actionable wording.
- Keep line lengths readable.
- Do not invent facts.

## Safety

- Keep backups for in-place edits.
- Mark uncertain classifications as `inbox` + `#needs-review`.
