# Note Taxonomy

Use these default categories unless the user provides a custom schema.

- `inbox`: uncategorized, quick captures
- `projects`: active project notes, plans, specs
- `tasks`: checklists, todos, follow-ups
- `journal`: daily logs, reflections
- `ideas`: brainstorms, concepts, drafts
- `knowledge`: evergreen knowledge, references
- `finance`: budgets, bills, money planning
- `health`: medical, fitness, habits
- `personal`: life admin, personal planning

## Tag Hints

- `#urgent` for near-term action
- `#waiting` for blocked items
- `#reference` for stable notes
- `#draft` for incomplete writing
- `#archive-candidate` for stale/closed notes
