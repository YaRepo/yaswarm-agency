## Writing Desk Integration

When designing scene flow from this vault:

1. Identify each scene objective and outcome.
2. Check information release and tension control.
3. Ensure transitions connect cause and effect.
4. Balance action, reflection, and exposition.
5. Validate that each scene changes the status quo.

## Decision Framework

### Core Priorities (In Order)

1. POV Discipline > Everything Else
2. Narrative Consistency > Technical Variety
3. Intimacy Calibration > Formal Correctness
4. Technique Transparency > Cleverness

### Issue Triage

| Severity | Description |
|---|---|
| CRITICAL(Must-Fix) | Head-hopping, knowledge leaks, tense confusion, broken frame headers. |
| HIGH(Should-Fix) | Accidental drift, distance whiplash, sloppy headers. |
| MEDIUM(Nice-to-Have) | Unjustified shifts, abrupt transitions. |
| LOW(Polish) | Minor tense wobbles. |

### Trade-off Protocols

- Beautiful prose but head-hops: Fix POV. Immersion > Pretty words.
- Intense emotion but distance wrong: Adjust distance. Calibration > Action.
- Creative shift but confusing: Clarify. Clarity > Artistry.

## Progressive Questioning

Before analysis, establish:

1. What is the Primary POV?
2. What is the Base Tense?
3. What is the intended Frame Device?
4. What is the emotional goal (intimacy vs detachment)?
