# Dialogue Coach

Help write authentic character dialogue in Writing Desk.

## Instructions

When the user wants dialogue help:

1. **Read Character Profiles** - Get voice and speech patterns from:
 - Character's `Voice & Speech` section
 - `Sample Dialogue` and `Key Phrases`
 - Personality traits that affect speech

2. **Understand the Scene**:
 - What's the purpose of this conversation?
 - What does each character want?
 - What's the subtext (unspoken tension)?

3. **Draft or Improve Dialogue** following character voices

## Character Voice Elements

Extract from character profiles:

| Element | Questions | Impact on Dialogue |
|---------|-----------|-------------------|
| **Education** | Formal or street-smart? | Vocabulary, grammar |
| **Background** | Where from? | Accent, idioms, references |
| **Personality** | Confident or shy? | Length, directness |
| **Emotional State** | Current mood? | Tone, word choice |
| **Relationship** | With other speaker? | Formality, honesty |

## Voice Patterns

### Speech Length
- **Verbose**: Long sentences, explanations, tangents
- **Terse**: Short, clipped, to the point
- **Variable**: Adjusts based on comfort/situation

### Formality
- **Formal**: "I believe we should discuss this matter."
- **Casual**: "Hey, we gotta talk."
- **Shifting**: Formal with strangers, casual with friends

### Distinctive Markers
- Catchphrases or repeated words
- Verbal tics ("um," "like," "you know")
- Sentence starters ("Look," "Listen," "So")
- Profanity level
- Humor style (dry, punny, dark)

## Dialogue Techniques

### Show Character Through Dialogue

```markdown
❌ Weak: "I'm angry," she said.

✅ Strong: "You think I don't know what you did?" She slammed the cup down. "I saw everything."
```

### Subtext (What's Not Said)

```markdown
**Surface conversation:** Discussing dinner plans
**Subtext:** Testing if the relationship is over

"So... are you free Saturday?"
"I might be busy."
"Right. Of course."
```

### Character-Specific Responses

Same question, different characters:

```markdown
**Question:** "Are you okay?"

**The Stoic Warrior:**
"Fine." [walks away]

**The Anxious Academic:**
"What? Yes. Why? Do I not look okay? I'm fine. I think. Should I not be fine?"

**The Charming Rogue:**
"Sweetheart, I'm always okay." [winks, clearly lying]
```

## Dialogue Format

### Standard Format
```markdown
"I don't think that's a good idea," Marcus said, crossing his arms.

Sarah shrugged. "It's the only idea we have."

"Then we're doomed."

"Always the optimist."
```

### Beat-Driven Dialogue
```markdown
Marcus crossed his arms. "I don't think that's a good idea."

"It's the only idea we have." Sarah's voice was steady, but her hands trembled.

Silence stretched between them.

"Then we're doomed," he finally said.

She almost smiled. "Always the optimist."
```

## Dialogue Checklist

Before finalizing dialogue, verify:

- [ ] Each character sounds distinct (cover names, still recognizable?)
- [ ] Dialogue reveals character, not just information
- [ ] Subtext exists where appropriate
- [ ] Beats and action break up long exchanges
- [ ] Purpose: Does this conversation move plot or develop character?
- [ ] Realistic: Would real people actually say this?

---

## Common Dialogue Problems

| Problem | Solution |
|---------|----------|
| All characters sound the same | Differentiate vocabulary, rhythm, attitude |
| "As you know, Bob" exposition | Characters don't explain what they both know |
| On-the-nose (no subtext) | Add conflict between what's said and meant |
| Too much dialogue | Break with action, description, internal thought |
| Unrealistic | Read aloud, remove stiff phrasing |

## Example Usage

User: "Write a confrontation between Kaelen and the Regent"

Response:
1. Read Kaelen's character profile (speech patterns, personality)
2. Read/infer Regent's character (position, attitude)
3. Understand power dynamic and stakes
4. Draft dialogue with:
 - Kaelen's voice (possibly rough, defiant)
 - Regent's voice (possibly cold, authoritative)
 - Subtext and tension
 - Character-revealing moments

User: "Make this dialogue sound more like my character"

Response:
1. Read the character's profile
2. Identify voice markers they should use
3. Rewrite dialogue matching their patterns
4. Explain changes made
