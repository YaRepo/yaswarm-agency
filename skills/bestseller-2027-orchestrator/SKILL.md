# Bestseller 2027 Orchestrator

## Purpose
Convert a draft into a commercially positioned product with measurable execution loops.

## Use This Skill When
- The user asks to make a book a bestseller, hit high sales, or build an end-to-end launch system.
- The user needs market-fit edits plus launch/distribution/marketing operations.
- The user wants a 2026 to 2027 roadmap with weekly metrics.

## Workflow
1. Intake and constraints.
- Confirm genre, audience, publication path (self, trad, hybrid), timeline, and budget bands.

2. Product-market positioning.
- Define one primary shelf + one secondary hook.
- Draft comp-title map and differentiator statement.
- Build subtitle/tagline alternatives.

3. Manuscript commercialization pass.
- Prioritize revisions that improve retention and word-of-mouth (opening velocity, chapter-end hooks, emotional signature scenes, quote-worthy lines).

4. Packaging and metadata.
- Build title tests, metadata set, BISAC/keywords, cover direction brief, blurb variants.

5. Launch architecture.
- Build phased plan: prelaunch, launch week, 90-day sustain.
- Build ARC pipeline, reviewer/creator outreach, and ad test matrix.

6. KPI and iteration loop.
- Track weekly leading indicators and decision thresholds.
- Trigger specific actions when metrics underperform.

## Operating Rules
- Do not promise bestseller outcome; optimize probability through execution quality and speed.
- Always set numeric targets, review cadence, and fallback branches.
- Prefer low-cost experiments before scaling paid spend.

## Safety Rules
- Do not fabricate market data, platform metrics, or sales projections.
- Separate assumptions from validated signals in all plans.
- Never recommend high-cost spend without a prior low-cost test result.
- Preserve author voice and project scope unless the user explicitly requests repositioning.
