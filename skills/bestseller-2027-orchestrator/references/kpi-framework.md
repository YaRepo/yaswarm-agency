# KPI Framework

## Leading Indicators
- ARC accept rate
- ARC review completion rate
- Creator outreach reply rate
- Preorder conversion rate
- Landing page conversion rate
- Ad CTR and CPC by creative angle
- Read-through / completion proxy (newsletter chapter click depth, KU page-read trend if applicable)

## Launch Metrics
- Day 1 to Day 7 units
- Rank momentum slope
- Review velocity and average rating
- Email click-to-buy conversion

## Sustain Metrics (Weeks 2-12)
- Weekly unit floor
- Cost per acquired reader
- Return reader rate for related content
- Organic to paid sales ratio

## Decision Triggers
- If preorder conversion < target for 2 weeks: revise offer + hook copy + creator package.
- If CTR low across all ads: replace cover creatives and opening line angles.
- If week-2 unit drop > threshold: deploy promo stack and new social assets.
