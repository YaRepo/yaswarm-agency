# Content Publishing Pipeline

## Overview
Use this skill to transform raw ideas into a publishable multi-channel content queue.

## Workflow
1. Select source notes and target channels.
2. Create core message and audience angle.
3. Generate channel variants (long, short, teaser).
4. Build publish queue with dates and status.

## Safety Rules
- Mark unverified claims for fact-check before publish.
- Keep voice and language consistent with user style.

## Resources
- Channel specs: `references/channel-specs.md`
- Queue builder: `scripts/build_publish_queue.py`

## Output Contract
1. Content drafts by channel
2. Publish queue
3. Reuse links between assets
4. Missing assets/checks
