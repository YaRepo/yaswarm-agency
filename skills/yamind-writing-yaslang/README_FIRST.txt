🗺️ WHAT IS THIS PROJECT?

   YaSlang_SKILL is a comprehensive Arabic language processing system
   that helps Claude AI understand and work with Arabic text.

   What it does:
   ✓ Detects which Arabic dialect is being used (5 dialects)
   ✓ Extracts word roots (trilateral & quadrilateral)
   ✓ Adds proper diacritics (vowel marks)
   ✓ Understands cultural context

   Coverage: 290M+ speakers across 5 major dialects
