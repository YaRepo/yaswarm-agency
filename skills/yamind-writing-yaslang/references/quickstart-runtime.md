# YaSlang Quickstart

Use this quick layer first; load full dialect/morphology docs only when needed.

## Fast Workflow
1. Confirm direction:
- Arabic -> English (`US` or `UK`)
- English -> Arabic (`MSA` or dialect)
- Dialect -> dialect / dialect -> English
2. Detect likely dialect (or ask user).
3. Set tone register (formal, neutral, conversational, street).
4. Translate/rewrite with meaning-first policy.
5. Return one alternate rendering for ambiguity.
6. Add brief QA note for terms, idioms, and uncertainty.

## Quick Dialect Cues
- Egyptian: `eh`, `mish`, hard `g` for `ج`
- Levantine: `shu`, `biddi`
- Gulf: `shlon`, `abi/abgha`
- Maghrebi: heavier French/Berber borrowings, compressed vowels
